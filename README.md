# Canon F-789SGA Emulator

This repository is named `Calculator-casio-improvedtry`, but the project being developed here is a **Canon F-789SGA scientific calculator emulator**.

## Current target
- Match the physical F-789SGA key layout from the reference calculator.
- Keep secondary SHIFT / ALPHA / BASE labels above the correct keys.
- Make the calculator interactive rather than a static image.
- Implement the calculator modes and functions incrementally.

## Current build
The first build focuses on a stable mobile UI and working basic calculator engine. Advanced modes will be implemented against the F-789SGA manual rather than approximated from a different calculator.
